# 作品的数据结构设计
比较值得注意的是1.图层要采用computed来做，目的是控制单一数据源，不要让数据冗余，增加开发成本
2. 采用vnode数据结构规范来抽象组件
3. 组件间有顺序，所以最好用数组，因为对象是没有顺序的

# 项目架构设计
B端编辑器前端（前后端分离提高开发效率，降低开发时间）
B端编辑器后端
H5和PC端
后台管理系统前端（前后端分离）
后台管理系统后端
自研统计服务（因为需要自定义事件，同时需要用openAPI方式提供数据信息，第三方无法满足需求）
单独的组件库服务（实现所见即所得，实现复用）
组件开发平台
脚手架创建
脚手架发布
B端，h5端和后台管理系统共用一个数据库
